代码开源，数据本地保存

三步开始使用

完成简单配置，即可开始流畅的双语阅读。

01

安装浏览器插件

下载并解压 ZIP 安装包，在浏览器扩展管理页开启“开发者模式”，加载已解压的插件。

02

填入你的 API Key

打开插件设置，选择 DeepSeek、OpenAI 或自定义接口，填入对应的 API Key。

03

开始双语阅读

打开网页，一键翻译全文，也可以悬停段落或选中文字查看译文。

常见问题

插件本身完全免费且 100% 开源。你需要自行配置大模型服务商的 API Key（例如 DeepSeek、OpenAI 等），接口调用费用直接由对应服务商按实际用量收取，没有任何中间商加价。
无机翻译针对 LLM 做了智能分段、并发控制和本地缓存管理。同一段落或重复浏览的网页会直接命中本地缓存，不仅毫秒级显示，也不会重复消耗 API Token。你也可以选择如 DeepSeek Flash 等高性价比极速模型。
不会。插件没有开发者自有后端服务器，你的 API Key、个人偏好和缓存都仅储存在本地浏览器中；翻译请求由浏览器直接发往你配置的大模型接口。
  1. 下载并解压 ZIP 安装包。
  2. 在浏览器地址栏输入对应地址：
    • Chrome：chrome://extensions
    • Edge：edge://extensions
  3. 开启“开发者模式”，点击“加载已解压的扩展程序”（Load unpacked），选择解压后包含 manifest.json 的文件夹。
请勿删除、移动或重命名解压后的文件夹，否则插件会失效（原 ZIP 包可删）。
