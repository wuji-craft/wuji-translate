无机翻译隐私政策

生效日期：2026 年 11 月 21 日
最后更新：2026 年 11 月 21 日

无机翻译（以下简称“本扩展”）重视你的隐私。本政策说明本扩展如何处理用户数据。

1. 不收集个人身份信息

本扩展不设开发者自有后端服务器，不收集、上传、出售或分享你的姓名、邮箱、手机号、账号信息或浏览历史。

你的 API Key、翻译内容、术语库和本地翻译缓存不会发送至无机翻译运营的服务器。

2. 本地存储

以下数据仅保存在当前设备的浏览器扩展本地存储中，不会自动同步至其他设备：

  • 你自行填写的第三方 AI 服务 API Key
  • 模型、翻译语言、显示模式、网站规则和其他设置
  • 本地术语库
  • 本地缓存的译文
  • 快捷键及其他使用偏好

你可以随时删除本扩展，或通过扩展设置清理相应的本地数据。

3. 第三方 AI 服务商

当你主动使用网页翻译、划词翻译、段落翻译或输入框翻译时，为完成翻译请求，本扩展会将必要文本直接从你的浏览器发送至你自行配置的第三方 AI 服务商 API。

发送内容可能包括待翻译文本、目标语言、必要上下文、已匹配术语，以及为保留网页格式所需的结构信息。请求不会经过无机翻译运营的服务器。

你可以自行选择和配置 AI 服务商或兼容 OpenAI API 格式的自定义服务。相关数据处理受你所选择服务商的隐私政策和服务条款约束。

请勿翻译包含密码、身份证号、银行卡号、商业机密或其他敏感个人信息的内容，除非你已充分了解并接受所选服务商的数据处理规则。

4. 发音服务

当你主动点击英文单词或短语的发音按钮时，对应文本可能会通过 HTTPS 发送至有道词典发音服务以获取语音音频。有道可能会按照其自身规则处理该请求及正常网络连接信息，例如 IP 地址。

对于其他语言、句子或段落，本扩展可能调用浏览器或操作系统提供的 Web Speech API。实际语音处理方式由浏览器、操作系统及相关服务提供方决定。

5. 数据安全

API Key 默认仅保存在扩展私有的本地存储中，仅供扩展设置页面和后台翻译任务按需使用。本扩展不会在日志、错误提示、截图或普通设置导出中展示你的完整 API Key。

但请注意，浏览器本地存储并非加密保险箱。请妥善保管设备和浏览器账户，并定期检查和更新 API Key。

6. 本政策的更新

如本扩展的数据处理方式发生实质变化，我们会更新本政策的“最后更新”日期，并在官网发布最新版本。
