Up and Running in 3 Steps

Complete a simple setup and start enjoying smooth bilingual reading.

01

Install the Browser Extension

Download and unzip the ZIP package. Open your browser’s extensions page, enable Developer Mode, and load the unpacked extension.

02

Add Your API Key

Open the extension settings, choose DeepSeek, OpenAI, or a custom endpoint, and enter the corresponding API key.

03

Start Reading in Two Languages

Open a webpage and translate the whole page with one click, or hover over a paragraph or select text to see its translation.
